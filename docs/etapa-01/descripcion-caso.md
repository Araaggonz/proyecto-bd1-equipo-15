# Descripción del caso — Verde Encanto

**Proyecto:** Verde Encanto — Sistema de Gestión de Ventas, Stock y Abastecimiento para un Vivero

El proyecto consiste en el diseño de una base de datos para un vivero y tienda de jardinería dedicado a la comercialización de diferentes productos como ser plantas, semillas, macetas, fertilizantes, sustrato, herramientas y otros productos relacionados con la jardinería.

Este sistema permitirá gestionar la información de los productos, categorías, clientes, proveedores, ventas, compras y stock. Registrará operaciones realizadas y mantendrá la información histórica necesaria para garantizar la consistencia de datos.

Se contemplarán situaciones propias del rubro como el control de stock mínimo, las mermas de productos ya sea por daños o deterioro, y el historial de precios, permitiendo contar con información confiable para la gestión del negocio.

El sistema estará orientado a mantener la **integridad, consistencia y trazabilidad** de la información.
